Built a calendly like app for scheduling appointments. However, there is a small change: along with the appointment, the user can also pick item from a list of items that the calender owner allows.

## Features

1. For the PoC, no sign up is required. Anyone can open the website and create a unique url by choosing a unique username. The URL/username will be used to access the calendar. We call this kind of user: creator.
2. One URL will only point to one calendar.
3. When setting this up,
   - creator will choose dates (by clicking on the dates on the calendar) that are available for bookings. These selections will be shown as blue blocks on the calendar. Blue means opening up for appointments. The rest will be shown as white. For, ex a creator selects 10 to 20 Sept 2026.
   - creator will create a list of items, add duration of item and add dates to each item. For example, an item should be dinner and add 10,11,12 to the item. ANother item could be badminton and add 10,11,12 to the item. A same date can be added to multiple items.
   - creator will save the settings.
   - create can now share the url with others.

User:

- user will open the url. If th url is never created, it shows 404. Otherwise open calender, (create caldnely like design) however, on each block, display items avaialbel to book. When someone clicks on an item on a particular date, show avaialble time.
- user can add phone number and name to book a slot.
- send confirmation on whatsapp to creator as well as user.
- mark that slot as booked.
- make sure to add 30 mins buffer between slots.
